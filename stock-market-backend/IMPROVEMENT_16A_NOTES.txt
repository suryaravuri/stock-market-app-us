#16A Strategy Baseline Freeze & Validation Run Tracking

Adds persisted validation_run and source attribution on production analytical signal/position rows.
Baseline SHA-256 fingerprints selected strategy/risk/service source files. Active runs fail closed with BASELINE_MISMATCH if those files drift.
Synthetic position_test_* tables are intentionally not linked and never count toward Phase 16 progress.

Endpoints:
POST /api/v1/analysis/validation-runs
GET /api/v1/analysis/validation-runs/active
GET /api/v1/analysis/validation-runs/{id}
GET /api/v1/analysis/validation-runs/{id}/progress
POST /api/v1/analysis/validation-runs/{id}/complete

Default strategy_version: SELECTION_ENGINE_V1
validation_phase: REAL_ANALYTICAL_VALIDATION
execution_mode: ANALYSIS_ONLY
