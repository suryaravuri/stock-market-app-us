#15F - Trade Journal & Performance Statistics

Purpose
- Aggregate completed analytical positions into a read-only trade journal and performance report.
- Keep all metrics per-share because analytical position quantity is not yet persisted.
- Never submit broker orders and never mutate production position tables.

Endpoints
GET /api/v1/analysis/trade-journal
GET /api/v1/analysis/trade-journal/performance

Filters
- scope: ALL | PRODUCTION | ISOLATED_TEST
- symbol: optional
- timeframe: optional
- limit: optional

Journal fields
- source / position id / test run id
- symbol / timeframe
- entry / exit / realized per share / realized R
- outcome WIN | LOSS | BREAKEVEN
- holding time / exit reason / closed time

Performance metrics
- total trades, wins, losses, breakeven
- win rate / loss rate
- average R / median R / expectancy R
- gross profit/loss and net realized per share
- profit factor
- average winner R / average loser R
- average holding time
- stop / target-2 / trailing-stop exit counts
- best / worst trade
- by-symbol and by-timeframe breakdowns

Safety
execution_mode=ANALYSIS_ONLY
broker_order_submitted=false
production_position_tables_mutated=false
No Alembic migration required.
