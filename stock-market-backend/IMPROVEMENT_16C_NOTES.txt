#16C - Frozen-V1 Watchlist Scan

Adds:
POST /api/v1/analysis/validation-runs/{validation_run_id}/watchlist-scan
    ?watchlist_id=1&timeframe=15Min

Safety / validation behavior:
- Requires ACTIVE Phase-16 validation run.
- Requires frozen strategy baseline_status=MATCH.
- Re-runs #16B market-data validation immediately before analysis.
- Only PASS / eligible symbols may invoke SetupService.
- DEGRADED/FAIL symbols are fail-closed as DATA_QUALITY_BLOCKED.
- Supports frozen V1 execution timeframe 15Min only.
- Existing SetupService advances real ANALYSIS_ONLY signal/position lifecycle.
- No broker order is submitted.
- Synthetic position_test_* tables are not involved.

Response exposes per symbol:
- market-data eligibility
- score/classification and risk/reward
- action/actionable
- breakout status
- persisted signal lifecycle state/event/cycle
- analytical position opening status
- state mutation indicators

No Alembic migration is required.
