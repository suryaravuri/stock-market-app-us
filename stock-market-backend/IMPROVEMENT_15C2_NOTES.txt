Improvement #15C-2 - Controlled Persistent Integration Test Mode

Purpose
- Validate real database persistence of the post-entry position lifecycle without contaminating production analytical position tables.
- Never call a broker and never mutate position_state / position_state_history.

New isolated tables
- position_test_state
- position_test_state_history

New endpoints
- POST   /api/v1/analysis/{symbol}/position-lifecycle/persistent-test
- GET    /api/v1/analysis/{symbol}/position-lifecycle/persistent-test/{test_run_id}
- GET    /api/v1/analysis/{symbol}/position-lifecycle/persistent-test/{test_run_id}/history
- DELETE /api/v1/analysis/{symbol}/position-lifecycle/persistent-test/{test_run_id}

Safety markers
- test_mode = CONTROLLED_PERSISTENT_VALIDATION
- execution_mode = ANALYSIS_ONLY
- persistence_mode = ISOLATED_TEST_TABLES
- broker_order_submitted = false
- production_position_tables_mutated = false
