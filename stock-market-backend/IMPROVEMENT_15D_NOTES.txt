Improvement #15D - Real Persistent Position Monitoring

Purpose
- Monitor only real, already-persisted analytical positions created after ENTRY_CONFIRMED.
- Consume newly stored completed regular-session candles exactly once.
- Keep terminal position states immutable.
- Expose current analytical unrealized P/L per share and R multiple.
- Never submit broker orders.

New endpoint
POST /api/v1/analysis/{symbol}/position-lifecycle/monitor?timeframe=15Min

Automatic integration
POST /api/v1/market/{symbol}/bars/sync now runs the same monitor after candle persistence and returns position_monitoring diagnostics.

Safety / idempotency
- ANALYSIS_ONLY remains enforced.
- Monitoring cannot create a position.
- last_evaluated_candle_time is the consumption cursor.
- Completed NO_STATE_CHANGE candles also advance the cursor, preventing duplicate evaluation.
- Incomplete and out-of-session candles never advance the state machine.
- STOP_HIT and TARGET_2_HIT are sticky terminal states.

Database
- No new migration required. Alembic head remains c41a8e2d90f1.
