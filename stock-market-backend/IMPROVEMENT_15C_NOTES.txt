Improvement #15C - Persistent Position Lifecycle Integration

Scope
- Connects ENTRY_CONFIRMED signal cycles to one persistent analytical position record.
- Remains ANALYSIS_ONLY. No broker order submission/cancellation/modification.

Hardening added
1. Strict opening gate:
   - signal lifecycle must be ENTRY_CONFIRMED
   - breakout.status must be ENTRY_CONFIRMED and confirmed=true
   - follow-through candle timestamp is mandatory
   - risk/stop/targets must have been recalculated after breakout
   - long stop/risk parameters must be valid
2. Idempotent persistence per (stock, timeframe, signal_cycle_number).
3. Entry/follow-through candle is never reprocessed as post-entry price action.
4. Only completed US regular-session candles can advance the persistent position.
5. Incomplete candles and out-of-session candles are ignored conservatively.
6. Terminal STOP_HIT/TARGET_2_HIT positions remain immutable.
7. New response diagnostics expose persistence/opening gate/processed candle counts.

No new DB migration is required. Existing b7d31f2a6c90 position tables are reused.
